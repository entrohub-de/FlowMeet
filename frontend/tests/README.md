# 测试工具目录

本目录包含用于调试和测试 FlowMeet 应用的各种工具。

## 📁 目录结构

```
tests/
├── scripts/      # 浏览器控制台测试脚本
└── pages/        # Next.js 测试页面
```

## 🔧 测试脚本 (scripts/)

这些 JavaScript 文件可以在浏览器开发者控制台中运行，用于调试特定功能。

### test-realtime.js
测试 Supabase Realtime 订阅功能。

**使用方法**：
1. 打开用户签到页面 `/user/checkin`
2. 打开浏览器控制台（F12）
3. 粘贴并运行脚本
4. 调用 `testRealtime()` 函数
5. 在 Host 端签到，观察控制台输出

**用途**：验证 WebSocket 连接和实时更新是否正常工作

---

### test-checkin-api.js
测试签到相关 API 调用。

**用途**：
- 验证签到 API 端点
- 测试签到码验证
- 检查 RLS 权限

---

### test-checkin-debug.js
签到功能调试工具。

**用途**：
- 调试签到流程
- 查看详细错误信息
- 验证数据库更新

---

### test-rls-policy.js
测试 Row Level Security (RLS) 策略。

**用途**：
- 验证 RLS 策略是否正确配置
- 测试不同用户角色的权限
- 检查数据访问限制

---

---

## 💡 使用建议

1. **开发环境专用**：这些测试工具仅用于开发环境，不应部署到生产环境
2. **安全提醒**：测试脚本可能包含敏感信息（如 API 密钥），请勿提交到公开仓库
3. **定期清理**：完成测试后，考虑删除不再需要的测试文件

---

## 🗑️ 清理建议

如果不再需要这些测试文件，可以安全删除整个 `tests/` 目录：

```bash
rm -rf frontend/tests
```
